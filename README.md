# После родов — памятка родильницы

PWA-памятка для пациенток послеродового отделения. Работает в браузере телефона, ставится на главный экран, открывается без интернета после первого захода.

Содержание основано на клинических рекомендациях РОАГ:
- «Нормальный послеродовый период (послеродовая помощь и обследование)», 2024
- «Роды одноплодные, родоразрешение путём кесарева сечения», 2024
- «Разрывы промежности при родоразрешении и другие акушерские травмы», 2023
- «Послеродовые инфекционные осложнения», 2024

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Само приложение |
| `qr.html` | Плакат A4 с QR-кодом для палаты (печать / PDF прямо из браузера) |
| `sw.js` | Офлайн-режим |
| `manifest.webmanifest`, `icon-*.png` | Установка на главный экран |
| `.nojekyll` | Чтобы GitHub Pages отдавал файлы как есть |

## Публикация на GitHub Pages

1. github.com → **New repository** → имя `posle-rodov` → Public → Create.
2. **Add file → Upload files** → перетащить все файлы из архива (не папку, а содержимое) → Commit.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты приложение будет по адресу
   `https://toporviking1-creator.github.io/posle-rodov/`
5. Плакат с QR: `https://toporviking1-creator.github.io/posle-rodov/qr.html` → «Печать / PDF».
   QR строится автоматически по адресу сайта.

## Как обновить текст

Текст симптомов и разделов — в `index.html`, массив `SYM` и функции `vRules`, `vSutures`, `vDays`, `vBreast`, `vAfter`.
После правки поменяйте `VERSION` в `sw.js` (например `pr-v2`), иначе у установивших останется старая версия.
